# Security policy

Please do not publish credentials, private user data, or an exploitable
vulnerability in a public issue. Use a private GitHub security advisory for
reports:

<https://github.com/dimpurr/voltscope/security/advisories/new>

Include the affected version, macOS version, reproduction steps, and the
smallest useful proof. We will acknowledge reports when practical and will
coordinate fixes through a private advisory before public disclosure.
